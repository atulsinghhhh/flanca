Before you ask us in a meeting

Six things we don't do.

You will find these out anyway. Finding them out from us is cheaper for both of us.

  • No GPS bus tracking, no biometric attendance. Both need hardware you would be buying. We import a biometric device's data instead.
  • English only. The strings are ready for Hindi and it is not done. If your teachers need Hindi, this is not ready for them yet.
  • No generated lesson videos. We built them, watched them, and removed them. A child gets better video free on YouTube.
  • No online exams or question banks. Marks entry and report cards, yes. Conducting an exam on a screen, no.
  • No reference schools. There are none, because there is no first school yet. If that is disqualifying, it should be.
  • No implementation team. Switching on is an afternoon and a spreadsheet, or it is not working. There is nobody to send.
